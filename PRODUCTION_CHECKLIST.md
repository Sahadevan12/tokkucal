## Decisions worth knowing about

- **No `tool_usages` table.** Storing session ID / hashed IP / user agent per calculation would be personal-data processing with no real product benefit here — Google Analytics (once you add `GOOGLE_ANALYTICS_ID`) already answers "which tools are popular" without us storing anything ourselves. This also means there's less for a future privacy audit to worry about.
- **Image tools never touch disk.** Uploaded images are decoded, compressed/resized and returned as an in-memory data URI in the same request — nothing is written to temporary storage or needs a cleanup job. This is stricter than "delete after processing," since there's never anything to delete.
- **QR codes are generated 100% client-side** (the `qrcode` npm package, loaded only on that one page) — content you type never reaches the server.
- **Calculators call small PHP services via `fetch()`**, not duplicate JavaScript math. This keeps the formulas in one authoritative, unit-tested place (`app/Services/`) while still feeling instant (no full page reload).
- **No separate `ToolController`.** The spec suggested one, but every tool already has its own dedicated controller (`CalculatorController`, `ImageController`, `QRCodeController`) and a clean route — an empty extra controller would just be dead code.

## Values you still need to configure

Nothing below was invented — these are genuinely yours to fill in.

```env
APP_URL=                    # your real domain, e.g. https://tokkucal.in
DB_DATABASE=                # from Hostinger hPanel → MySQL Databases
DB_USERNAME=
DB_PASSWORD=

MAIL_HOST=                  # SMTP details so the contact form can send email
MAIL_USERNAME=
MAIL_PASSWORD=
MAIL_FROM_ADDRESS=

ADSENSE_ENABLED=false       # set true once approved
ADSENSE_CLIENT_ID=          # ca-pub-XXXXXXXXXXXXXXXX from your AdSense account
GOOGLE_ANALYTICS_ID=        # G-XXXXXXXXXX from Google Analytics
GOOGLE_SITE_VERIFICATION=   # HTML tag value from Google Search Console
CONTACT_EMAIL=              # where the contact form sends messages
```

Also needed after AdSense approval:
- **`public/ads.txt`** — create this file with the exact line Google gives you in your AdSense account (Sites → your site → "View site's ads.txt"). Don't add this until you have the real line.

## Before you go live

1. Pick a domain (not yet decided — see `DEPLOYMENT.md` for the Hostinger setup once you have one)
2. Fill in the `.env` values above
3. Follow `DEPLOYMENT.md` end to end
4. Submit `/sitemap.xml` to Google Search Console
5. Apply for AdSense with the live domain once there's real content and traffic
